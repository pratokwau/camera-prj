# 🤚 Finger AR Overlay

AR-проект на Python: камера захватывает руку, а картинка привязывается к кончикам 4 пальцев через перспективное преобразование. Двигаешь пальцами — картинка тянется, сжимается, поворачивается в реальном времени.

## Как это выглядит

```
   ┌─────────────┐         ┌───●  (index)
   │             │              │
   │   КАРТИНКА  │         ●───┤  (middle)
   │             │          │
   │             │         ●────  (ring)
   └─────────────┘              ● (pinky)
```

4 угла картинки → 4 кончика пальцев. Всё что между — интерполируется перспективой.

## Стек

| Компонент | Библиотека |
|-----------|-----------|
| Камера | OpenCV |
| Детекция руки | MediaPipe Hands (21 landmark) |
| Перспективное преобразование | OpenCV `warpPerspective` |
| Матрицы | NumPy |

## Как это работает

1. **MediaPipe Hands** находит 21 точку руки в реальном времени.
2. Берутся кончики 4 пальцев: **index (8)**, **middle (12)**, **ring (16)**, **pinky (20)**.
3. `cv2.getPerspectiveTransform` вычисляет матрицу из 4 углов картинки → 4 кончиков.
4. `cv2.warpPerspective` деформирует картинку под текущую позу пальцев.
5. Оверлей накладывается на кадр с учётом альфа-канала (прозрачность PNG).
